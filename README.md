Vice Sunset Cover Studio: an offline web app that turns your photos and a caption into GTA 6-style poster art — comic-book panels you can crop and position, sunset/neon/noir/palm colour grades, and big bold outlined lettering — exported as a PNG in 1080×1080, 1080×1350 or 1920×1080.

## Run it

```sh
node serve.ts
```
